# Windows runtime notices

The Windows release was built with MSYS2 MinGW-w64 GNU Fortran 15.2.0 and statically linked GNU/MinGW runtime support. Original notices from the installed GCC libraries, libgfortran, winpthreads and MinGW CRT packages are preserved here. The GCC Runtime Library Exception is in `gcc-libs/COPYING.RUNTIME`. Microsoft MPI is installed separately and is not redistributed in this archive.

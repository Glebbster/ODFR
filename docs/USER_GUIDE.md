# Руководство пользователя

## Подготовка

Соберите программу по инструкции в [`README.md`](../README.md).

Для расчёта создайте отдельный каталог и поместите в него:

- `namODFR.nam`;
- ODF-файл параметров;
- EPR-файл параметров для каждого спектра;
- экспериментальные `.esr`;
- `weight` или `weight.dat`, если используются внешние веса.

## Запуск

ODFR 5 читает `namODFR.nam` из текущего каталога.

```powershell
cd C:\path\to\calculation
C:\path\to\ODFR\out\windows\bin\ODFR5_serial.exe
```

## `Kcontrol`

| Значение | Режим |
|---:|---|
| `1` | Остановка |
| `2` | Одиночный расчёт |
| `3` | Подбор NL2SOL |
| другое | Подбор MINPACK при наличии варьируемых параметров |

Примеры входов находятся в `tests/smoke/input` и `tests/hgo_h2_rt/input`.

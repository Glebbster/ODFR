# Входные и выходные файлы

## `namODFR.nam`

Файл задаёт задачи и имена остальных файлов.

```text
run
ODF_INPUT  ODF_OUTPUT  NSPEC
EPR_INPUT  EPR_OUTPUT  ESR_INPUT  SPECTRUM_OUTPUT  ODFTYPE
end
```

Для `NSPEC > 1` строка спектра повторяется нужное число раз.

## EPR `.par`

Позиционный файл параметров спектра. За шаблон следует брать входы из `tests` или файл, записанный самой программой.

## ODF `.par`

Позиционный файл параметров ODF. Результирующее имя задаётся в `namODFR.nam`.

## Экспериментальный `.esr`

После строки `Spectr:` читаются пары «поле — интенсивность».

## Веса

`iwflag` задаёт режим:

| Значение | Режим |
|---:|---|
| `0` | без весов и нормировки |
| `1`–`3` | деление остатка на `rmsn` |
| `4` | внешний файл весов |
| `5` | внешний файл весов и деление на `rmsn` |

Для режимов 4 и 5 программа ищет `weight`, затем `weight.dat`.

## Результаты

Основные имена результатов задаются в `namODFR.nam`. Журнал расчёта записывается в `history`.

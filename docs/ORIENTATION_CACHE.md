# Кэш спектров локальных ориентаций

В расчёте MOMD ODFR4 сохраняет спектр каждого узла после вычисления
непрерывной дроби и уширения. Программа заново применяет макроскопические
веса ODF, интегрирует по углам и складывает вклады сайтов с их амплитудами.

В пределах одной оценки модели запросы разделяют локальные спектры при
точном совпадении подготовленных параметров ядра, сетки поля, размера БПФ
и фактического сдвига сайта относительно первого. Для усреднения MOMD
входной угол образца и макроскопический параметр `dc20` входят в веса.
Для одиночного угла программа выполняет обычный расчёт. В MPI каждый
процесс кэширует только свои узлы и выполняет ту же общую редукцию.

При ранней сходимости CSCG передаёт в продолженную дробь коэффициенты
завершённых шагов. Для одного шага CFS вычисляет скалярную дробь.
При попадании в кэш программа берёт готовый спектр и восстанавливает
эти коэффициенты в текущей ячейке. В подборе проверяется владелец ячейки.
Для отсутствующей, перезаписанной или непригодной записи выполняется `FULL`.
[Причина изменения CSCG и проверка очереди на HGO](CSCG.md)

## Режимы

- Кэш работает в одноразовых расчётах и при оценке невязки для NL2SOL.
- В подборе MINPACK действует классическая схема вычисления невязки и
  Якобиана с её собственным выбором `FULL` и `CFONLY`.
- В одноразовом расчёте `Kcontrol=2` программа по-прежнему очищает
  диагонали перед каждым спектром. Кэш хранит до 32 МиБ активных частей
  коэффициентов на ранг и восстанавливает их в исходные ячейки при
  обращении к готовому спектру. Это сохраняет состояние CG для связанных
  сайтов в текущем спектре и для следующих задач в том же процессе.
  Ограничение хранилища для подбора составляет 800 наборов.

Кэш включён по умолчанию. Для сравнения можно задать
`ODFR4_ORIENTATION_CACHE=0`, чтобы отключить кэш, или
`ODFR4_ORIENTATION_CACHE=full`, чтобы дополнительно увидеть число полных
угловых расчётов. Значение `stats` включает кэш и выводит на stdout числа
`full`, `cfonly` и `spectra` для каждого ранга на каждой оценке модели.
Поле `cfonly` сохранено в формате статистики кэша и равно нулю.
Режимы диагностики доступны в тех же расчётах, что и кэш.

## Проверка кеша

Соберите нужные цели и выполните:

```powershell
ctest --test-dir out/windows-mpi -L orientation_cache --output-on-failure
```

Комплектные тесты сравнивают расчёты с кешем и с полным вычислением в последовательной сборке и на двух процессах MPI. Для собственного расчёта используйте режимы `stats` и `full` в загрузке из отдельных копий одной задачи. Команды запуска см. в [README](../README_RU.md).

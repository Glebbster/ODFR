# HGO H2 RT regression case

В `input` хранится минимальный воспроизводимый набор входных данных из
`EPR_modeling/HGO_H2_RT_final`:

- `namODFR.nam` — описание задачи;
- `ODF.par` — начальные параметры ODF;
- `uglerodnik.par` — начальные параметры EPR;
- `s1.esr` — экспериментальный спектр из 1024 точек.

Файл `weight` из исходной папки не нужен этому расчёту: в
`uglerodnik.par` установлен `iwflag=0`, поэтому пользовательские веса
отключены. Чтение отдельного файла весов проверяет smoke-тест.

Старые исполняемые файлы, `history`, итоговые `.par`/`.dat` и изображения не
копируются: это результаты конкретных прошлых запусков, а не входные данные.
Тест каждый раз запускается в чистом каталоге и проверяет создание
`ODFres.par`, `final1.par`, `final1.dat`, полный loss-report и ожидаемый
численный диапазон `SSE_W`.

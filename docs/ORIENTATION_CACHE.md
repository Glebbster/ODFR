# Кэш спектров локальных ориентаций

В расчёте MOMD ODFR5 сохраняет спектр каждого узла после вычисления
непрерывной дроби и уширения. Программа заново применяет макроскопические
веса ODF, интегрирует по углам и складывает вклады сайтов с их амплитудами.

При подборе NL2SOL записи доступны и на следующих оценках той же задачи.
Например, проба амплитуды сайта для Якобиана повторно использует локальные
спектры. Для этого должны совпасть биты подготовленных параметров спектра,
сетка поля, размер БПФ и фактический сдвиг сайта относительно первого.
В MOMD входной угол образца и макроскопический параметр `dc20` входят
в веса. В расчёте одной ориентации угол `PSI` входит в ключ спектра.
В MPI каждый ранг хранит собственные узлы и выполняет обычную редукцию.

При ранней сходимости CSCG передаёт в продолженную дробь коэффициенты
завершённых шагов. Для одного шага CFS вычисляет скалярную дробь.
При попадании в кэш программа берёт готовый спектр и восстанавливает
эти коэффициенты в текущей ячейке. Если изменилась только обработка
линии, например гауссово уширение или сдвиг поля `SpcShift`, подбор
повторяет расчёт непрерывной дроби и свёртку с сохранёнными коэффициентами
(`CFONLY`). При изменении параметров матрицы, стартового вектора или
настроек CG программа выполняет `FULL`, если для этого набора ещё нет записи.
[Причина изменения CSCG и проверка очереди на HGO](CSCG.md)

## Режимы

- Кэш работает в одноразовых расчётах и при оценке невязки для NL2SOL.
- В подборе MINPACK действует классическая схема вычисления невязки и
  Якобиана с её собственным выбором `FULL` и `CFONLY`.
- В одноразовом расчёте `Kcontrol=2` локальные спектры MOMD могут
  использоваться повторно внутри одной оценки. Перед каждым спектром
  программа очищает диагонали рабочего хранилища.
- В начале нового задания NAM кэш очищается. Спектры и пары
  коэффициентов занимают суммарно до 112 МиБ на ранг. Дополнительно
  выделяются служебные структуры. При заполнении вытесняются записи,
  к которым дольше всего не обращались. При отказе выделения памяти
  расчёт продолжается без сохранения соответствующего результата.

Кэш включён по умолчанию. Для сравнения можно задать
`ODFR4_ORIENTATION_CACHE=0`, чтобы отключить кэш, или
`ODFR4_ORIENTATION_CACHE=full`, чтобы дополнительно увидеть число полных
угловых расчётов. Значение `intra` ограничивает повторное использование
одной оценкой, `intra-stats` дополнительно включает статистику.
Значение `stats` сохраняет обычный режим подбора и печатает для каждого
ранга номер оценки `eval`, количества полных вычислений `full`, повторов
из коэффициентов `cfonly` и готовых спектров `spectra`. Поле `cross`
показывает, сколько обращений использовало результат предыдущей оценки,
а `bytes` — объём сохранённых спектров и коэффициентов.

## Проверка кеша

Соберите нужные цели и выполните:

```powershell
ctest --test-dir out/windows-mpi -L orientation_cache --output-on-failure
```

Комплектные тесты сравнивают расчёты с кешем и с полным вычислением в последовательной сборке и на двух процессах MPI. Для собственного расчёта используйте режимы `stats` и `full` в загрузке из отдельных копий одной задачи. Команды запуска см. в [README](../README_RU.md).
